# Vallisneri–Stancari Correspondence

**A knowledge graph and digital edition of 30 letters from Antonio Vallisneri to Francesco Vittorio Stancari (1705–1708)**

🔗 **Web application:** <https://luciagiagnolini12.github.io/vallisneri-stancari/>

A project by **Lucia Giagnolini** and **Ilaria Maggiulli**, Archivio Storico dell'Università di Bologna.

---

## About the project

The Historical Archive of the University of Bologna (Archivio Storico dell'Università di Bologna) holds a small collection that it bought on the antiquarian market in 2013: 30 letters written by the physician and naturalist **Antonio Vallisneri** (1661–1730) to the Bolognese mathematician **Francesco Vittorio Stancari** (1678–1709). The letters date from 1705 to 1708.

The letters discuss insects, chameleons, the lucimetro, acquisitions for Vallisneri's museum and his correspondents across the Republic of Letters. They also record a circulation of specimens, instruments, books, manuscripts and observations. Archival description is organised around the single document, so it captures these exchanges only in part.

This project combines archival and philological methods with computational ones. It turns the letters into an **event-centric knowledge graph** of persons, places, organisms, specimens, objects, texts and exchanges. The graph describes the metadata of the letters and also their content. Every statement links back to the passage it comes from.

## Workflow

| # | Stage | Description |
|---|-------|-------------|
| 1 | **Transcription** | Full semi-diplomatic transcription. Original spelling is preserved, abbreviations are expanded and punctuation is regularised. |
| 2 | **Data model** | An ontology-based model that reuses established vocabularies (see below). |
| 3 | **Extraction & reconciliation** | Schema-constrained extraction with an open-weights LLM (**Gemma 3 12B**) run locally via **Ollama**. The extracted entities are reconciled with **VIAF**, **GeoNames**, **Wikidata** and **GBIF**. |
| 4 | **Validation** | Curators review every proposed entity in a dedicated web application. Each correction is recorded and classified as *invented*, *wrong name*, *wrong reference* or *missing*. |
| 5 | **Publication** | Linked Open Data release following the FAIR principles, plus the web application. |

The letters and their analysis never left the authors' computers. The pipeline has no usage costs and can be reproduced.

## Data model

| Ontology | Used for |
|----------|----------|
| [CIDOC CRM](https://cidoc-crm.org/) | Documents, persons, places, events. Movements and exchanges are modelled as `E9 Move` and `E10 Transfer of Custody` |
| [CRMsci](https://cidoc-crm.org/crmsci/) | Scientific observation |
| [Darwin Core](https://dwc.tdwg.org/) | Organisms, specimens, taxonomic identifications |
| [Darwin-SW](https://github.com/darwin-sw/dsw) | Darwin Core terms expressed in RDF |
| [PROV-O](https://www.w3.org/TR/prov-o/) | Provenance of statements |
| [HiCO](https://marilenadaquino.github.io/hico/) | Interpretative acts and their criteria |

Many statements are interpretations. Examples are matching an 18th-century vernacular name such as *pesce colombo* or *mosca rosiseca* to a modern taxon, or a historical toponym to a present-day place. Each interpretation is attributed to an agent: either the language model or a curator. The graph therefore distinguishes three kinds of statement:

- generated by the model and confirmed by a curator;
- modified by a curator;
- added manually.

```
  movements.json        Movements and transfers
```

## Web application

- **Letters**: read each transcription with the entities it mentions highlighted.
- **Entities**: browse persons, places, organisms and works with their VIAF, GeoNames, Wikidata and GBIF identifiers.
- **Network**: entities as nodes, sized by the number of letters they appear in and linked when they co-occur in a letter. This is an exploratory tool.
- **Map**: places mentioned in the letters, each linked to the letters that cite it and to its authority records.

The application is a static page. To run it locally, serve the folder over HTTP so that the browser can load the data files:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Limitations and ongoing work

- The corpus is small and one-sided: Stancari's replies have not survived.
- Some intermediaries involved in the circulation of objects are not named in the letters.
- Entity validation is complete. **Validation of events and transfers is in progress.** This second phase aims to reconstruct the circulation of objects and specimens, including, where the evidence permits, the route of the chameleons to Padua.
